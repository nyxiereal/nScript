# Verified Windows cleanup targets

22 additional paths, verified against vendor documentation or upstream source. `H|` means the signed-in user's `%USERPROFILE%\` (not every user). As with the original config, `AppData\Local` and `AppData\Roaming` assume the standard Windows profile layout; redirected/custom locations are not discovered.

These entries use the existing general cleanup: files older than 24 hours, or all eligible files with `-Force`; excluded extensions and protected paths still apply. This removes app files/data, **not a registered uninstall**: running processes, services, drivers, registry registrations, protected files and excluded shortcuts may remain. No new process-killing, service/driver removal, shared-folder targets, or discovery scans were added. Saves, accounts and clip-library metadata inside these targets are intentionally included, not just caches.

## Deliberately omitted

- Discord PTB/Canary: public support material verified standard Discord, not exact variant paths.
- LDPlayer 9 and modern Nox install roots: vendor examples/legacy paths did not establish current defaults.
- WeMod/Wand: the old support URL returned 404 during verification; no guessed rebrand directory.
- Shared Razer/Overwolf/VirtualBox roots, VPN/security/network tooling, arbitrary game libraries and custom/portable installs: no broad collateral deletion targets.

Verification is documentary, not a local installation test. No installer, launcher, or cleaning code was executed.
