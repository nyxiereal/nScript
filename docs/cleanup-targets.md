# Verified Windows cleanup targets

`H|` means the signed-in user's `%USERPROFILE%\` (not every user). These entries use the existing general cleanup: files older than 24 hours, or all eligible files with `-Force`; excluded extensions and protected paths still apply. Install/data folders are **not** discovered on custom drives. Evidence below is from vendor documentation or upstream source, not community path guesses.

| Target (`H|` suffix) | Purpose | Primary evidence | Scope / caveat |
| --- | --- | --- | --- |
| `AppData\Local\Bloxstrap` | Bloxstrap install and data | [Installer.cs L22](https://github.com/bloxstraplabs/bloxstrap/blob/02db76006741f039b79ac7547b8054d7f3ccfc05/Bloxstrap/Installer.cs#L22) sets `Path.Combine(Paths.LocalAppData, App.ProjectName)`; [App.xaml.cs L15-L21](https://github.com/bloxstraplabs/bloxstrap/blob/02db76006741f039b79ac7547b8054d7f3ccfc05/Bloxstrap/App.xaml.cs#L15-L21) names the normal build `Bloxstrap`; [Paths.cs L9](https://github.com/bloxstraplabs/bloxstrap/blob/02db76006741f039b79ac7547b8054d7f3ccfc05/Bloxstrap/Paths.cs#L9) uses Windows LocalApplicationData. | Per-user default; install location can be changed; QA builds have a different name. |
| `AppData\Local\Fishstrap` | Fishstrap install and data | [Installer.cs L23](https://github.com/fishstrap/fishstrap/blob/988db40e3e259489f95e4c7ec40f8dbf5685f309/Bloxstrap/Installer.cs#L23) combines LocalAppData with `App.ProjectName`; [App.xaml.cs L15-L21](https://github.com/fishstrap/fishstrap/blob/988db40e3e259489f95e4c7ec40f8dbf5685f309/Bloxstrap/App.xaml.cs#L15-L21) defines normal `Fishstrap`. | Per-user default; custom install directory/QA builds excluded. |
| `AppData\Local\Programs\PrismLauncher` | Prism Launcher install | [win_install.nsi.in L11-L12](https://github.com/PrismLauncher/PrismLauncher/blob/7de6e963c258827971640ba8b41c95659a0ba962/program_info/win_install.nsi.in#L11-L12) sets `$LOCALAPPDATA\Programs\@Launcher_CommonName@`; [CMakeLists.txt L11-L12](https://github.com/PrismLauncher/PrismLauncher/blob/7de6e963c258827971640ba8b41c95659a0ba962/program_info/CMakeLists.txt#L11-L12) defines `PrismLauncher`. | Per-user installer default; registry override, portable, and custom installs excluded. |
| `AppData\Roaming\PrismLauncher` | Prism Launcher data | [Prism Launcher Data Locations](https://prismlauncher.org/wiki/getting-started/data-location/) lists Windows `%APPDATA%/PrismLauncher`. | Per-user default; portable and changed data directory excluded. |
| `AppData\Roaming\ModrinthApp` | Modrinth App data | [Modrinth storage location](https://support.modrinth.com/en/articles/8797641-modrinth-app-storage-folder-location) states Windows `%AppData%\ModrinthApp\` by default. | Per-user default; custom App directory excluded; pre-0.8.0 `com.modrinth.theseus` not targeted. |
| `AppData\Local\Programs\lunarclient` | Lunar Client launcher install | [Lunar Client shortcut instructions](https://support.lunarclient.com/solutions/no-lunar-client-shortcut) say `C:\Users\%username%\AppData\Local\Programs\lunarclient`, containing `Lunar Client.exe`. | Per-user default path only. |
| `.lunarclient` | Lunar Client game data | [Lunar Client support](https://support.lunarclient.com/solutions/external-software-interfering-with-lunar-client) calls `%USERPROFILE%\.lunarclient\settings\game` the Lunar Client directory for stored accounts; this path lies under `.lunarclient`. | Per-user default; contains accounts/settings, not just cache; custom/portable locations excluded. |
| `AppData\Roaming\Vencord` | Vencord mod data | [constants.ts L22-L31](https://github.com/Vendicated/Vencord/blob/3374b8a9d8f6b051c64204917360293aad7f5d75/src/main/utils/constants.ts#L22-L31) joins `app.getPath("userData")`, `..`, `Vencord` and writes settings there; [Electron userData docs](https://www.electronjs.org/docs/latest/api/app#appgetpathname) define `userData` under `appData` on Windows; [Discord support](https://support.discord.com/hc/en-us/articles/209099387--Windows-Installer-Errors) identifies the default `%AppData%\Discord` folder. | Per-user default; `VENCORD_USER_DATA_DIR` / `DISCORD_USER_DATA_DIR` overrides excluded. |
| `AppData\Roaming\Vesktop` | Vesktop client data | [constants.ts L13-L30](https://github.com/Vencord/Vesktop/blob/a02035be2083e09666ed250bd977325c35f5be95/src/main/constants.ts#L13-L30) uses `app.getPath("userData")` for data; [package.json L67-L68](https://github.com/Vencord/Vesktop/blob/a02035be2083e09666ed250bd977325c35f5be95/package.json#L67-L68) gives Electron's preferred `productName: Vesktop`; [Electron docs](https://www.electronjs.org/docs/latest/api/app#appgetpathname) specify `userData = appData/<app name>` on Windows. | Per-user nonportable default; portable `Data` and `VENCORD_USER_DATA_DIR` excluded. |
| `AppData\Roaming\BetterDiscord` | BetterDiscord mod data | [betterdiscord.ts L14-L20](https://github.com/BetterDiscord/BetterDiscord/blob/9fc106e8e53e51589374c05cfb03b35f4149d0a2/src/electron/main/modules/betterdiscord.ts#L14-L20) sets `bdFolder` to parent of Discord Electron `userData` plus `BetterDiscord`; [Electron docs](https://www.electronjs.org/docs/latest/api/app#appgetpathname) place `userData` beneath Windows `appData`; [Discord support](https://support.discord.com/hc/en-us/articles/209099387--Windows-Installer-Errors) identifies the default `%AppData%\Discord` folder. | Per-user default; altered Discord data location excluded. |

Skipped: Discord PTB/Canary install/data directories. Discord's public support articles document standard Discord paths but did not verify exact PTB/Canary paths; community reports are insufficient. No speculative PTB/Canary entries were added.
